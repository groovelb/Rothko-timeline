# 로스코 타임라인 — 비주얼 디렉션

---

## 메타포

### "미술관의 연대기 벽 (Chronicle Wall)"

미술관 복도 끝, 하얀 벽에 걸린 단 하나의 긴 패널.
가까이 다가가야 글씨가 보이고, 더 가까이 가면 그림이 보인다.

- 벽 = 여백. 정보가 아닌 **침묵**이 기본 상태
- 축 = 벽에 새긴 가느다란 **흠집**. 시간이 지나간 자국
- 감정선 = 벽 위에 번진 **안료의 얼룩**. 선명하지 않고, 스며들어 있다
- 작품 = 벽에 걸린 **작은 색면들**. 유일하게 색을 가진 존재
- 이벤트 = 벽 아래 **캡션 라벨**. 미술관 작품 옆 설명판처럼

**핵심 원칙: 색은 오직 로스코에게서만 온다.**
UI 크롬, 축, 텍스트는 모두 무채색. 화면에서 색이 보이면 그것은 로스코의 것이다.

## 참조 디자인 사조

### 1차 — 스위스 타이포그래피 (International Typographic Style)

- Josef Müller-Brockmann의 그리드 체계
- 정보의 위계를 **크기와 위치**로만 표현
- 장식 없음. 선 하나, 점 하나가 의미를 가짐
- 타임라인의 축, 틱, 라벨 배치에 직접 적용

### 2차 — 미술관 전시 그래픽 (Museum Exhibition Design)

- 작품 옆 캡션: 작은 산세리프, 벽과 거의 같은 톤
- 연대기 패널: 가는 선 + 최소한의 텍스트 + 넓은 간격
- 화이트큐브 갤러리의 **절제된 경외감**
- 정보는 찾는 사람에게만 보인다

### 3차 — 에디토리얼 모노그래프 (Art Monograph)

- Phaidon, Thames & Hudson 계열 미술 서적
- 세리프 제목 + 산세리프 본문의 이중 체계
- 도판(plate)과 텍스트 사이의 **의도적 거리**
- 여백이 곧 디자인

## 색감 (Color)

### 원칙: 크롬은 지운다, 색은 로스코가 채운다

```
UI 크롬 팔레트 (무채색만)
──────────────────────────────────
배경        #FAFAFA   거의 백색, 미세한 따뜻함 (gallery white)
축/틱       #D4D4D4   존재하되 주장하지 않는 선
라벨 1차    #1A1A1A   가장 중요한 텍스트 (연도, 작품명)
라벨 2차    #8A8A8A   부가 정보 (설명, 카테고리)
라벨 3차    #B8B8B8   호버 시에만 나타나는 텍스트
호버 배경   #F0F0F0   미세한 톤 변화로 인터랙션 힌트
구분선      #E8E8E8   시기 구분, 거의 보이지 않는

감정 밴드 팔레트 (로스코 작품에서 추출)
──────────────────────────────────
유년·이민     #A0937D   토프 — 흙, 이민선의 빛바랜 갈색
예일·좌절     #8B7D6B   웜그레이 — 아직 색을 찾지 못한 시기
뉴욕·시작     #8B6914   오커 — 첫 불꽃
The Ten       #A07B3D   앰버 — 동료와의 연대
이혼·전환     #4A235A   딥 퍼플 — 신화의 심연
재혼·돌파     #E67E22   번트 오렌지 — 사랑과 돌파
클래식기      #E74C3C   카드뮴 레드 — 절정의 붉은 빛
벽화기        #922B21   마룬 — 분노가 응축된 어둠
암흑기        #1C1C1C   챠콜 — 빛이 빠져나간 캔버스
종결          #000000   블랙 — 침묵
```

### 색 사용 규칙

- 감정 밴드: 불투명도 0.15~0.4 범위. 배경에 **스며든** 느낌
- 작품 색면: 불투명도 1.0. 유일하게 **선명한** 색
- 호버 시: 해당 시기의 밴드 색이 툴팁 좌측 보더(3px)로만 등장
- 몰입 모드: 작품의 background 색이 전체 화면을 서서히 물들임

## 타이포그래피

### 이중 서체 체계

```
세리프 (감성, 시간, 역사)
──────────────────────────────────
서체: Cormorant Garamond (Google Fonts)
용도: 연도, 작품 제목, 인용문, 시기 이름
무게: Light 300 / Regular 400
특성: 올드스타일 세리프, 가늘고 우아한 획
     — 로스코 시대(1940-60s)의 인쇄물 감성

산세리프 (정보, 기능, 현재)
──────────────────────────────────
서체: Pretendard (기존 시스템 유지)
용도: 설명문, 카테고리 라벨, UI 요소
무게: Regular 400 / Medium 500
특성: 뉴트럴 산세리프, 정보 전달에 충실
```

### 타이포 위계

```
Level 1  시기 제목        Cormorant Light 28px   #1A1A1A
Level 2  작품 제목        Cormorant Regular 16px  #1A1A1A
Level 3  연도            Cormorant Light 13px    #8A8A8A
Level 4  이벤트 라벨      Pretendard Regular 12px #1A1A1A
Level 5  부가 설명        Pretendard Regular 11px #8A8A8A
Level 6  인용문          Cormorant Italic 15px   #8A8A8A
```

### 에디토리얼 규칙

- 자간(letter-spacing): 세리프에 +0.02em, 대문자 라벨에 +0.08em
- 행간(line-height): 본문 1.6, 제목 1.2, 인용문 1.8
- 정렬: 좌측 정렬 기본. 인용문만 중앙 정렬
- 대문자: 시기 코드(CLASSIC_B)와 카테고리 라벨만 uppercase

## 에디토리얼 키워드

```
Restraint          절제 — 보여줄 수 있지만 보여주지 않는다
Reverence          경외 — 미술관에 들어설 때의 조용한 긴장감
Negative Space     여백 — 비어있는 것이 가장 많은 것을 말한다
Monochrome Frame   무채색 프레임 — 액자는 그림보다 조용해야 한다
Slow Reveal        천천히 드러남 — 다가갈수록 보이는 구조
Ink on Paper       종이 위의 잉크 — 디지털이지만 인쇄물의 질감
Single Voice       하나의 목소리 — 색은 오직 로스코의 것
Horizon Line       수평선 — 모든 것이 하나의 선 위에 놓인다
Breathing Room     숨 쉴 공간 — 요소 사이의 거리가 리듬이 된다
Catalog Tone       도록의 톤 — 설명하되 해석을 강요하지 않는다
```

## 시각적 밀도 가이드

```
전체 화면 대비 요소가 차지하는 비율

여백 (배경)        60~70%
감정 밴드 (반투명)   15~20%
작품 색면 블록       5~8%
축 + 이벤트 틱       3~5%
텍스트 라벨          3~5%

→ 화면의 2/3는 비어 있어야 한다
```

## 반면교사 — 하지 않을 것

- 그라데이션 배경, 글래스모피즘, 네온 악센트
- 호버 시 과도한 스케일/바운스 애니메이션
- 인포그래픽 스타일의 아이콘, 일러스트, 장식 요소
- 타임라인 위 화살표, 말풍선, 배지
- 로스코 작품의 실제 이미지 사용 (CSS 색면 재현만)
- 다크 모드 (갤러리 화이트가 본질)
