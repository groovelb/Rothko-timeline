# 로스코 타임라인 — 미니멀 기획서

## 1. 핵심 구조: 단일 좌표계

```
  감정(+)
    ↑        ○작품                    ○작품  ○작품
    │       ╱    ╲                  ╱              ╲
    │     ╱        ╲              ╱                  ╲
    │   ╱            ╲          ╱                      ╲
────●─────●────●───────●──●──●──────●───●────●──────●───●──→ 시간
    │  이벤트들(Y=0)         ╲  ╱                        │╲
    │                         ╲╱                    ○작품  ╲
    │                      ○작품                            ╲
    │                                                    ○작품
  감정(-)
```

- **X축** — 시간 (1903→1970)
- **Y축** — 감정 상태 (정성적, 숫자 없음. 위=긍정, 아래=부정)
- **이벤트** — X축 위(Y=0)에 고정. 사실(fact)은 땅 위에 있다
- **작품** — 감정선 위에 배치. 그림은 감정 위에 떠 있다
- **감정선** — 이벤트와 작품을 잇는 내러티브 곡선

## 2. 왜 이 구조인가

이벤트(Y=0)와 작품(감정선) 사이의 **수직 거리**가 의미를 만든다:

- 1950년대: "MoMA 개인전" 이벤트는 축 위에 → 작품들은 한참 위에 떠 있음 → **현실도 좋고 감정도 높았던 시기**
- 1968년: "대동맥류 진단, 별거" 이벤트는 축 위에 → 작품들은 한참 아래에 → **현실의 사건이 감정을 무너뜨린 시기**
- 1958년: "시그램 벽화 거부" 이벤트는 축 위에 → 작품은 축 바로 아래쯤 → **외적으로는 명성이 있었지만 내면의 갈등이 시작된 순간**

관람자는 "무슨 일이 있었는지(축)"와 "그때 어떤 그림을 그렸는지(곡선)"를 **동시에 비교**할 수 있다.

## 3. 데이터 구조

> 모든 원본 데이터는 `src/data/rothko/` 에 위치

| 파일 | 내용 | 건수 |
|------|------|------|
| `rothko_events.json` | 생애 이벤트 + 감정 곡선 + 시기 구분 | 이벤트 46개, 곡선 포인트 43개 |
| `rothko_works.json` | 작품 + CSS 색상 + 감정 Y좌표 + 경매 기록 | 작품 50개 |

### 이중 시기 구분 체계

데이터는 **두 가지 관점**의 시기 구분을 병행한다:

**미술사적 시기 (7개)** — `periods[]`
작품의 양식 변화 기준. 구상기(FIG) → 신화기(MYTH) → 멀티폼(MULTI) → 클래식(CLASSIC_B) → 시그램(SEAGRAM) → 후기(DARK) → 최후기(FINAL)

**감정/전기적 시기 (10개)** — `biographical_periods[]`
감정 곡선의 구간 기준. 유년·이민 → 예일·좌절 → 뉴욕·시작 → The Ten·정체성 → 이혼·전환 → 재혼·돌파 → 클래식기·정점 → 벽화기·갈등 → 암흑기 → 종결

타임라인에서 **감정 밴드의 색/두께**는 감정적 시기를, **작품의 분류 라벨**은 미술사적 시기를 따른다.

### 작품 데이터 스키마

각 작품은 다음 시각화 필드를 포함:

```jsonc
{
  "id": "W026",
  "year": 1953,
  "title": "No. 61 (Rust and Blue)",
  "period": "CLASSIC_B",           // 미술사적 시기
  "composition_type": "classic",   // 시각화 유형
  "color_blocks": [                // CSS 색면 재현용
    { "color": "#B86030", "ratio": 0.5 },
    { "color": "#305080", "ratio": 0.5 }
  ],
  "background": "#906040",         // 색면 사이/뒤 배경색
  "emotion_y": 0.85,               // 감정 곡선 Y좌표 (-1.0 ~ 1.0)
  "collection": "MOCA, LA",
  "auction_record": null
}
```

`composition_type` 종류:
- `figurative` — 초기 구상 작품 (W001–W008)
- `mythomorphic` — 신화/초현실 (W009–W013)
- `multiform` — 멀티폼 전환기 (W014–W018)
- `classic` — 2~3 색면 수직 배열 (W019–W034, W041)
- `seagram` — 시그램 벽화 (W035–W040)
- `dark` — 후기 어두운 작품 (W042–W047)
- `final` — 최후기 블랙/그레이 (W048–W050)

### 감정선의 시각적 표현

감정선은 단순한 선(line)이 아니라 **두께와 색을 가진 밴드(band)**로 표현한다.
각 속성은 `biographical_periods[]`에 데이터화됨.

- **두께** (`band_thickness`) — 감정의 진폭/불안정성. 안정기엔 얇고, 격동기엔 두꺼움
- **색상** (`band_colors`) — 해당 시기 로스코 작품의 지배적 팔레트와 동일
- **경계 흐림** (`blur_intensity`) — 로스코 회화처럼 가장자리를 블러 처리. 0.2(선명)~0.8(흐릿)

## 5. 이벤트 (X축 = Y=0)

축 위에 **수직 틱(tick) + 텍스트**로 표시. 전체 **46개 이벤트** (`rothko_events.json`).

### 이벤트 카테고리

데이터의 `category` 필드로 시각적 구분 가능:
- `life` — 개인사 (출생, 결혼, 이혼, 사망 등)
- `art` — 양식 전환 (멀티폼 시작, 클래식 도달 등)
- `career` — 커리어 (전시, 커미션, 수상 등)
- `emotional` — 감정적 전환점 (종교적 경험 발언, 팝아트 혐오 등)

### 줌 레벨별 표시 전략

46개를 한 화면에 모두 표시하면 과밀. **significance 필드**로 단계 표시:

| significance | 줌 아웃 (전체) | 줌 인 (상세) |
|-------------|---------------|-------------|
| `critical` (5개) | 항상 라벨 표시 | 상세 표시 |
| `high` (18개) | 점만 표시, 호버 시 라벨 | 라벨 표시 |
| `medium` (18개) | 숨김 | 점 표시, 호버 시 라벨 |
| `low` (5개) | 숨김 | 호버 시만 표시 |

**critical 이벤트 (항상 보임)**:
1. 1914 — 아버지 사망 (E004)
2. 1949 — 클래식 양식 도달 (E024)
3. 1958 — 시그램 커미션 전환점 (E031)
4. 1968 — 대동맥류 진단 (E039)
5. 1970 — 사망 (E044)

## 6. 작품 (감정선 위에 배치)

전체 **50개 작품** (`rothko_works.json`). 각 작품의 `emotion_y` 값에 따라 감정 곡선 위에 배치.

### CSS 색면 재현

실제 이미지 대신 `color_blocks[]` 데이터로 **로스코풍 색면 블록을 CSS로 재현**:

```css
/* classic 타입 예시: No.61 Rust and Blue */
.rothko-painting {
  width: 60px;
  height: 80px;
  display: flex;
  flex-direction: column;
  gap: 4px;
  padding: 6px;
  background: #906040;           /* background 필드 */
  border-radius: 2px;
}
.rothko-painting .field {
  flex: 1;
  filter: blur(1px);             /* 로스코 특유의 경계 흐림 */
  border-radius: 1px;
}
.field:nth-child(1) { background: #B86030; }  /* color_blocks[0] */
.field:nth-child(2) { background: #305080; }  /* color_blocks[1] */
```

## 7. 인터랙션 설계

### 7-1. 기본 상태 — "한눈에 보는 전체"

```
┌────────────────────────────────────────────────────────────────┐
│                                                                │
│  감정(+)                                                       │
│    │            ○         ○  ○                                 │
│    │         ○        ○ ○  ○  ○                                │
│    │       ╱ ○  ╲      ╱ ○     ╲                               │
│    │     ╱        ╲  ╱           ╲                              │
│    │   ╱            ╲              ╲   ○                        │
│  ──●──●──●──●──●──●──●──●──●──●──●──●──●──●──●──●──●──●──→    │
│    │03  13 14 23 29 35 40 45 49 54 58 61 64   68 70            │
│    │                ╲╱                          ╲  ╱            │
│    │                                      ○  ○  ╲╱  ○          │
│    │                                          ○    ○           │
│  감정(-)                                        ○              │
│                                                                │
│  ● 이벤트    ○ 작품    ━ 감정선                                  │
│                                                                │
└────────────────────────────────────────────────────────────────┘
```

페이지 로드 시 **전체 타임라인이 한 화면에** 보인다. 작품은 작은 색면 블록(○)으로, 이벤트는 축 위의 점(●)으로 보인다. 감정선의 색과 두께가 시기별로 다르다.

### 7-2. 호버 — 이벤트

축 위의 이벤트 점에 마우스를 올리면:

```
                    ┌─────────────────────────┐
                    │ 1958                     │
                    │ 시그램 벽화 납품 거부      │
                    │                          │
                    │ 고급 레스토랑을 위한 그림을  │
                    │ 그리는 것에 환멸을 느끼고   │
                    │ 완성된 벽화의 납품을 거부   │
                    └─────────┬───────────────┘
                              │
  ────────────────────────────●──────────────→
```

- 툴팁은 X축 위에 나타남 (감정선/작품을 가리지 않도록)
- 해당 시기의 감정선 색상을 툴팁 왼쪽 보더에 적용
- `category`에 따라 아이콘 구분 (life=○, art=◆, career=□, emotional=△)

### 7-3. 호버 — 작품

감정선 위의 작품 블록에 마우스를 올리면:

```
              ┌───────────────────────┐
              │  ┌─────────────────┐  │
              │  │  ██████████████ │  │  ← color_blocks로 재현
              │  │  ██████████████ │  │
              │  │                 │  │
              │  │  ██████████████ │  │
              │  │  ██████████████ │  │
              │  └─────────────────┘  │
              │  Orange, Red, Yellow  │
              │  1961 | 236×206cm     │
              │  Christie's $86.9M    │  ← auction_record 있으면 표시
              └───────────────────────┘
```

- 작은 블록이 **확대**(scale up)되며 상세 정보 표시
- 색면 재현이 커지면서 로스코 특유의 blur 경계가 더 잘 보임
- 주변 요소는 살짝 dim 처리

### 7-4. 클릭 — 작품 몰입 모드

작품을 클릭하면 **전체 화면이 해당 작품의 색면으로 전환**:

```
└────────────────────────────────────────────────┘
```

- 배경이 작품의 `background` 색상으로 서서히 전환
- 로스코가 원했던 **몰입적 관람 경험**을 디지털로 재현
- 해당 시기의 이벤트·맥락도 함께 표시 (동일 year 이벤트 연결)
- ←→ 로 작품 간 이동 가능

### 7-5. 스크롤 줌 — 시기 확대

마우스 휠 또는 핀치로 **X축 스케일을 확대/축소**:

```
축소 (전체 일생) — critical 이벤트 5개 + 대표 작품 ~15개:
●──────●──────────────────●──────────●───●→
1903  1914               1949      1968 1970

확대 (1955-1962) — 숨겨졌던 이벤트/작품 등장:
●────●────●──●──●────●──●────●──●────●──→
1955  56  57 58  59  60  61  62
 │    │   │  │   │   │   │   │
판매증가 종교적 시그램 포시즌스 철회 MoMA 팝아트
       경험  수락  식사       회고전 고립
```

- 축소: 전체 내러티브 조망 (기본 뷰)
- 확대: 특정 시기의 이벤트와 작품을 촘촘하게 탐색
- 확대하면 `significance: medium/low` 이벤트와 추가 작품이 나타남

## 8. 감정선과 작품의 관계 — 핵심 인사이트

이 타임라인에서 가장 흥미로운 읽기는 **감정선의 위치 vs 작품 색상의 관계**:

| 패턴 | 의미 | 예시 |
|------|------|------|
| 감정↑ + 밝은 작품 | 감정이 직접 작품에 반영 | 1950s 클래식기 — 밝은 오렌지/옐로 (y=0.85~0.95) |
| 감정↓ + 어두운 작품 | 고통이 작품에 투영 | 1960s 암흑기 — 블랙/그레이 (y=-0.7~-1.0) |
| 감정↓ + 강렬한 작품 | 고통을 에너지로 전환 | 1958 시그램 — 분노가 강렬한 마룬으로 (y=-0.3) |
| 감정↑ + 깊은 작품 | 행복 속 내면 탐구 | 1950 초 — 인정받으며 더 깊은 색면 탐구 |
| 감정 급변 + 밝은 작품 | **시차(time lag)** | 1961 Orange,Red,Yellow — MoMA 회고전 반등(y=0.3)이지만 곧 추락 |

이 관계를 관람자가 **스스로 발견**하게 하는 것이 이 타임라인의 목적이다.

## 10. 핵심 요약

**이 타임라인은 단 하나의 좌표계로 세 가지를 동시에 전달한다:**

1. **X축(시간)** 위의 이벤트 46개 → 무슨 일이 있었는가
2. **감정선(곡선 43포인트 + 색 + 두께)** → 그때 어떤 상태였는가
3. **감정선 위의 작품 50개** → 그래서 어떤 그림을 그렸는가

관람자는 하나의 차트를 보면서 **사건→감정→작품**의 인과를 자연스럽게 읽게 된다.
